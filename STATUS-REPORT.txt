⚙️ SLOT & PRICING CONFIGURATION

Time Slots:
  Morning:   06:00 - 14:00  →  ₹500/hour
  Afternoon: 14:00 - 18:00  →  ₹750/hour
  Evening:   18:00 - 22:00  →  ₹1000/hour

Payment Structure:
  • Advance: ₹100 per slot (non-refundable)
  • Balance: Pay at turf
  • Example: 3 slots (₹1500 total) = ₹300 advance, ₹1200 at turf

Booking Rules:
  • Slots confirmed only after advance payment verified
  • Cancelled bookings free up slots immediately
  • Past slots auto-disabled (updated every 30 seconds)
  • Host can block slots for maintenance/private events

🚀 NEXT STEPS FOR PRODUCTION

1. Configure Razorpay Payments
   • Get test keys from dashboard.razorpay.com
   • Add to backend/.env:
     RAZORPAY_KEY_ID=rzp_test_xxxx
     RAZORPAY_KEY_SECRET=xxxx
   • Test with Razorpay test cards
   • Switch to live keys when ready

2. Setup PostgreSQL Database
   • Get free PostgreSQL from:
     - Neon (neon.tech) - Recommended
     - Supabase (supabase.com)
     - Render PostgreSQL
   • Add DATABASE_URL to backend/.env
   • Switch to production server (node server.js)

3. Configure WhatsApp Notifications (Optional)
   • Get Meta WhatsApp Business API access
   • Add credentials to backend/.env:
     WHATSAPP_TOKEN=your-token
     WHATSAPP_PHONE_ID=your-phone-id
     HOST_WHATSAPP=919876543210

4. Deploy to Production
   • Option A: Render.com (free tier, sleeps after 15 min)
   • Option B: Fly.io (~$2/month, always-on)
   • Option C: VPS ($5/month, full control)
   • See README.md for deployment guides

5. Add Custom Domain
   • Point DNS to your hosting provider
   • Add domain to Razorpay dashboard
   • Update ALLOWED_ORIGINS in .env

🆘 TROUBLESHOOTING

Server won't start:
  → Check port 4000 isn't already in use
  → Run: netstat -ano | findstr :4000

Can't login to admin:
  → Default: admin / <password from backend/.env ADMIN_PASSWORD>
  → Reset: cd backend && node setup-host.js

Payment failing:
  → Add Razorpay keys to .env
  → Check console for errors
  → Verify test mode in logs

Database errors:
  → Use dev-server.js for testing
  → Or add valid DATABASE_URL
